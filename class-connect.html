Class Connect

2nd Grade A parent group

A private Facebook group for Holy Family Catholic School 2nd Grade A families in Orlando. Share birthdays, school events, reminders, and parent notes — all in one place.

Private Facebook group

The group is private. Request to join, then a class parent admin will approve you. Only 2nd Grade A families, homeroom moms, and teachers.

Open the Facebook group
  1. Tap Open the Facebook group. It opens in a new tab.
  2. Tap Request to join.
  3. Wait for a class parent admin to approve you.
  4. Then you can post, comment, and share with the class.

  • Talk together

    Parents, homeroom moms, and teachers can post and reply in one private group.

  • Birthdays

    Share a child’s birthday so classmates can celebrate.

  • School events

    Spirit days, Mass, International Night, and family nights — same 2026–27 year as this site.

  • Class only

    This group is just for HFCS 2nd Grade A. Not the whole school.

Who gets in

A parent admin approves each request. Use your real name and your child’s first name so we know you belong in 2nd Grade A.

Seesaw is still the official way the teacher shares classwork. This Facebook group is extra — parent-to-parent, unofficial, and not the school website.
